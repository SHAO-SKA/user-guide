使用须知
===========

欢迎使用中国 SKA 区域中心（cnSRC）平台。

本文档是 cnSRC 用户使用文档，内容包括账号注册与审批、平台登录、作业运行、数据传输和软件环境使用等。

本手册的功能分区与操作流程参考 SRCNet 平台通用设计，若界面按钮名称或页面路径有调整，请以 cnSRC 平台实际显示为准。


平台说明
---------

cnSRC 面向 SKA 相关科学研究与数据处理场景，提供 CPU/GPU 算力、共享存储和常用科学软件环境。

用户可通过平台 Web 界面与命令行方式使用资源，并结合作业调度系统完成批处理任务。


账号与资源开通
---------------

1. 新用户请先在平台完成注册并提交审批材料。

2. 账号审批和资源配额由管理员按项目进行分配。

3. 外网访问需要提前完成 VPN 或固定 IP 白名单开通。

4. 如需开通或调整资源，请联系管理员邮箱：shaoska@shao.ac.cn。


使用规范
---------

.. warning::

   1. 计算资源按平台规则进行计量和扣费，具体配额、计量口径和可用资源类型以平台“用量/限额”页面为准。

   2. 平台默认提供基础软件环境与开源工具支持，不提供商业软件授权及其售后支持。

   3. 用户应对自行安装的软件和数据负责，包含版权、合规与安全风险。

   4. 请勿在登录节点直接运行高负载任务，应通过调度系统提交作业。

   5. 如因不当使用导致平台资源、数据或声誉受损，平台保留追责权利。
