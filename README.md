## Preview the document locally

First create a virtual environment and install dependencies (`pip install -r requirements.txt`), then:

```bash
$ make html        # Chinese HTML
$ make html-en     # English HTML
```

Generated pages are under `_build/html` (and `_build/html/en` for English).
